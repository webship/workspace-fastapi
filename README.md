# @webship.co/workspace-fastapi

FastAPI for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that makes a FastAPI app
from the official full-stack template (or takes one from its repository) and serves it from containers of its own (the
app's Python in the app's container, its database beside it), the FastAPI step pack wired into the workspace's testing
setup of that app, and its AI items. The workspace is container-based (DDEV by default).

The builder, the tests and CI come with the first release, `1.0.0`.
